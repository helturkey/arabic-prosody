# PHP Arud — العروض العربي لـ PHP

مكتبة PHP 8.1+ بلا اعتماديات: تحوّل النص العربي **المشكول** إلى التقطيع الثنائي (١ متحرك / ٠ ساكن)، ثم تكشف البحر لـ **شطر أو بيت أو قصيدة كاملة أو سطر شعر تفعيلة**، مع شرح كل تفعيلة وما طرأ عليها من زحاف أو علة.

> **الحالة: 1.0.0-rc.1.** الجانب الهندسي جاهز للإنتاج (أنواع صارمة، تحقق من المدخلات، اختبارات، حدود). أما **القواعد العروضية** فهي ترميز أمين للمنقول في الكتب لكنها **لم تُراجَع بعد من متخصص**، والمدوّنة الاختبارية صغيرة (15 بيتًا من 6 بحور). اقرأ `docs/GRAMMAR.md` و`RELEASE_STATUS.md` قبل الاعتماد عليها في عمل حرِج.

## الاستعمال

```php
$a = new Arud\Analyzer();

$a->analyze($shatr, side: 'sadr');                 // شطر
$a->analyzeVerse($sadr, $ajuz);                    // بيت: وسيطان
$a->analyzeVerse([$sadr, $ajuz]);                  // أو مصفوفة
$a->analyzeVerse(['sadr' => $s, 'ajuz' => $j]);    // أو مصفوفة بمفاتيح
$a->analyzePoem([[$s1,$j1],[$s2,$j2]]);            // قصيدة: مصفوفة أزواج / قائمة مسطّحة / نص متعدد الأسطر
$a->analyzeAuto($x);                               // يكتشف الشكل تلقائيًّا
$a->detectMeter($x);                               // اسم البحر أو null
$a->analyzeFreeVerse($line);                       // شعر التفعيلة
```

صيغة النص: سطر لكل بيت بالشكل `صدر *** عجز`، أو سطران لكل بيت.

## ما تفعله

* **تشترط التشكيل**: النص غير المشكول لا يحصل أبدًا على ثقة «high».
* **صريحة في الالتباس**: الكامل بالإضمار مطابق ثنائيًّا للرجز؛ يُعاد البحران مع `ambiguous_with`.
* **قواعد حسب الموضع** (حشو/عروض/ضرب) مع **التصريع** في مطالع القصائد.
* **31 صيغة**: التام والمجزوء والمشطور والمنهوك ومخلع البسيط، وتسميات فرعية (أحذ الكامل، الكامل المقطوع). الصيغ الموسومة `rare` قواعدها متساهلة وتُسقف ثقتها عند `medium`.
* أسماء الموسوعة غير المنمذجة (الموشح، الدوبيت، المواليا …) تُعاد من `MeterCatalog::extended()` مع سبب عدم دعمها، و`resolveName()` يربط الاسم بالصيغة.
* لا تغطي: القافية، التشكيل الآلي، تدوير الأبيات.

سطر الأوامر: `vendor/bin/arud verse "…" "…"` و`arud poem file.txt --json` و`arud meters`.
